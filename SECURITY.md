# Security policy

Please report vulnerabilities privately to **security@[YOUR DOMAIN]** or through GitHub's
private vulnerability reporting on this repository. Do not open public issues for security bugs.

We aim to acknowledge reports within 2 working days and to fix critical issues within 7 days.
Please give us reasonable time to fix an issue before disclosing it.

In scope: the web app, API and infrastructure in this repository.
Out of scope: denial-of-service testing, social engineering, physical attacks, third-party services.

Our security design is described in `docs/06-security.md`.
