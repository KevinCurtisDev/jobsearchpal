# Content data files

Machine-readable content used by the backend and frontend. Edit these, not code, to change wording.

| File | Used by |
| --- | --- |
| `banned_phrases.json` | CV writing checker (Stage 2) |
| `cv_conventions.json` | Country conventions in the CV builder (Stage 2) |
| `core_questions.json` | Interview prep core questions (Stage 10) |
| `frontend/src/features/self-check/questions.json` | "Should I move?" questions, verdict wording, fix tips, wellbeing note (lives in the frontend because it runs in the browser) |
| `guides/*.md` | Free guides (referrals, end of search, long searches, different starting points). Front matter has `checked`; statutory figures re-checked every April |
| `hiring_stages.json` | Published hiring-funnel pass rates, sources and progress-framed messages for stage odds and the How hiring works guide (Stage 4, 7) |
| `linkedin_rules.json` | LinkedIn profile checklist, limits, LinkedIn clichés, keyword-gap thresholds (Stage 3) |
| `consents/` | Exact consent wording, versioned and hash-locked (Stage 1) |
| `competencies.json` | STAR story tagging and coverage map (Stage 10) |
| `tax_tables/` | Offer comparison take-home pay (create in Stage 10; update every January) |
