# Legitimate interests assessments (LIAs)

Every category in the data inventory that relies on legitimate interests (GDPR Art 6(1)(f))
points to one of these files. CI fails if the file is missing.

Each LIA answers the three tests: **purpose** (is the interest legitimate?), **necessity**
(is the processing needed, or is there a less intrusive way?), **balancing** (do the
person's interests, rights and reasonable expectations override ours?).
